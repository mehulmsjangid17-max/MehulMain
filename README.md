## 🌟 Live Demo & Deployment

This project is built using pure **HTML5, CSS3, and Vanilla JavaScript** with **zero build steps** or external dependencies, making it 100% compatible with **GitHub Pages** out of the box!

### How to host on GitHub Pages:
1. Push this repository to GitHub.
2. Go to your repository's **Settings** tab.
3. In the left sidebar, click on **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select branch: `main` (or `master`)
   - Select folder: `/ (root)`
5. Click **Save**. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<your-repo-name>/`

## 🚀 Features

- **⚡ Modern Dark Tech Aesthetic**: Curated color palette, sleek radial gradients, and subtle background glow orbs.
- **💎 Glassmorphism Design**: High-performance backdrop blur, glowing borders, and card depth effects.
- **📱 100% Responsive**: Tailored across all screen sizes (320px, 375px, 768px, 1024px, 1440px+) with zero horizontal scroll.
- **🧭 Dynamic Navigation Bar**: Sticky header with backdrop blur, active scroll spy, and an accessible mobile hamburger drawer.
- **💻 Interactive Code Window**: Live Swift code preview with animated dashed orbits and floating badges.
- **📈 Animated Statistics Counters**: Count-up animation for members, events, and projects using `IntersectionObserver`.
- **🛠️ Technical Domains**: Glassmorphism vertical cards for *Web Development*, *AI & Machine Learning (CoreML)*, *Cyber Security*, and *iOS & App Development*.
- **🏆 Events & Activities**: Cards with full schedule modal for flagship hackathons (`SwiftHack '26`), tech talks, and code labs.

- **📋 Join Us & Event Modals**: Accessible pop-up dialogs with client-side form validation and custom toast notifications.
- **⬆️ Back to Top**: Smooth scroll-to-top utility button.

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup (WCAG compliant)
- **CSS3**: Vanilla CSS, Custom Properties (CSS variables), Glassmorphism, CSS Grid, Flexbox, Keyframe animations
- **JavaScript**: Pure Vanilla ES6+, IntersectionObserver API, requestAnimationFrame
- **Typography**: Google Fonts (*Space Grotesk*, *Plus Jakarta Sans*, *Fira Code*)
- **Icons**: Inline SVGs for fast rendering without CDN dependencies

## 💻 Local Development

Run with any static HTTP server or open directly:

```bash
# Using Python
python3 -m http.server 3000

# Or using Node (if installed)
npx serve .
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
